Winnow

    Connect Winnow

    Winnow writes straight to your private notes repo. It needs a fine-grained personal access token scoped to that one repo with Contents: Read and write. Nothing else.

    The token is stored in this browser only (localStorage). It never leaves your device except to call api.github.com. Use a token scoped to a single repo so a leak can do nothing but write notes.

    Writing somewhere else?

    Create a token → Resource owner: your account · Repository access: only your notes repo · Permissions: Contents → Read and write.

    Delete this note?

    It disappears from Winnow, but the original capture stays in archive/ in your notes repo, so it is recoverable.
