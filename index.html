    Signed in with GitHub

    Winnow writes straight to your private notes repo, so it needs permission to reach it. Signing in with GitHub is the easy way, and there is nothing to type or remember.

    Prefer a token? The fallback below takes a fine-grained personal access token scoped to that one repo with Contents: Read and write. It is stored in this browser only and never leaves your device except to call api.github.com.

    One tap. Nothing to type, nothing to remember. Access is limited to your notes repo and expires on its own.

    Use a personal access token instead

    Create a token → Resource owner: your account · Repository access: only your notes repo · Permissions: Contents → Read and write.
